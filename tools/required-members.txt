# Every value, exception, constructor and type the required part of the
# Standard ML Basis Library specifies, one per line, as Structure.member.
#
# "Required" is the Basis Library's own term: the structures a conforming
# implementation must provide.  Optional structures (IntInf, Int64, Word32,
# Real32, Array2, Posix, Unix, Windows, Socket, PackWord*, PackReal*, the
# Wide* family, ...) are deliberately absent -- naming an absent structure is
# a compile-time error, so a portable suite cannot reference them at all.
#
# Lines beginning with # are comments.  tools/check-coverage.sh checks that
# each entry is exercised somewhere under src/tests.
