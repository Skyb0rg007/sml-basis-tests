# Every value, exception and constructor of the *signatures the optional
# structures introduce*, one per line, as Structure.member.
#
# The line this list draws is deliberate.  The optional structures fall into
# two kinds.  Most of them -- Int32, Int64, IntInf, Word32, Word64, SysWord,
# FixedInt, Real32, Real64, IntVector, RealArray and the rest -- are further
# instances of INTEGER, WORD, REAL and the MONO_* signatures, whose members
# are already in tools/required-members.txt and already exercised by the
# generic bodies in src/tests/gen-*.sml.  Listing Int32.quot beside Int.quot
# would check the same line of the same file twice and say nothing new.
#
# What is listed here is the surface those structures add: the part of INT_INF
# that INTEGER does not describe, and PACK_WORD, PACK_REAL and ARRAY2, which
# no required structure implements.  Those are the members a suite could
# genuinely forget.
#
# tools/check-coverage.sh checks that each entry is exercised somewhere under
# src/optional, resolving the generic files against every instance the
# per-implementation profiles apply them to.  Lines beginning with # are
# comments.
